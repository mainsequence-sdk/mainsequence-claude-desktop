The MainSequence pane is redesigned. A persistent header shows the signed-in
account, the organization environment, running operations (open Activity) and
Settings. Five sections replace the former seven: Home (next steps, this session's
repository status, recent activity), Code (one list of remote and local repositories
with a detail view that is the operation target), Projects, Agents and Tools
(connected MCPs first; Add MCP searches releases; the tool explorer sits under
Advanced). Lists use rows with inline actions, each view has one primary button,
statuses use Claude's success, warning and error colours, unavailable actions are
shown disabled with a reason, and confirmations appear above the view instead of
replacing it.

Talk fills Claude's input with `/ms @<agent-handle> ` so the command names the agent
that receives the message; the explicit `/ms agent <uid> <message>` and
`/ms task <uid> <message>` forms still work and a bare `/ms <message>` is refused with
the prepared handles. Plugin tool results reach Claude as content blocks (the MCP
server's own blocks are forwarded), and an uncertain delivery can be released with
**Allow sending again** without resending anything.
Example questions in an agent's details fill the input when pressed, and the composer
band gains Switch agent. The running count also appears in Claude's status line.

Carries the 0.4.9 pane recovery, select paging and setup progress, the 0.4.10 MCP
names, and the MainSequence Projects workspace flow. No worker request, backend,
credential or configuration contract changed.

Validation: 80 Node tests, nine native Desktop simulator tests, native loader
validation, typechecking, documentation and portable distribution checks passed on
Desktop's bundled Code 2.1.299. Bundles devtools 0.2.8 from the integrity-checked
local archive described in the README. Update from the MainSequence marketplace and
reload the plugin in the Code chat. Node 22+ required.
