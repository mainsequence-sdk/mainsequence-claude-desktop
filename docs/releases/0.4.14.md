MCP tool results reach Claude as Messages API content blocks. Text passes through;
MCP images (`data` with `mimeType`) become base64 image blocks for PNG, JPEG, GIF and
WebP; resource links, embedded resources, audio and other block kinds become text,
with binary payloads omitted rather than inlined. Previously such blocks were forwarded
in MCP's own shape, which Claude's core does not accept. Includes the 0.4.13 startup
fix for tools after `/reload-plugins`.

Validation: 88 Node tests, nine native Desktop simulator tests, loader validation and
distribution checks passed; the real end-to-end Back Office Helper conversation and MCP
call were rerun against the installed copy. Bundles devtools 0.2.8. Node 22+ required.
