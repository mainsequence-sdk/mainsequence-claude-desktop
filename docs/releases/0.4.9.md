Fixes the intermittent blank MainSequence pane when an MCP exposes more than 63 tools. Claude rejects dropdowns with over 64 options, including the empty selection. Large catalogs now have Previous/Next controls, retain the selected item across pages, and show the selected tool's description. The same limit is enforced for repository, branch, environment and connection selectors.

MainSequence opens from its footer button or `/ms`; startup and reloads no longer open the pane automatically. Restored panes can initialize independently, and rendering/startup failures offer a display retry without replaying operations.

Local repository setup immediately shows progress beside disabled setup buttons, supports cancellation, keeps progress visible when navigating, and reports completion or failure with folder actions. MCP discovery no longer waits for connected-tool registration, and late responses cannot replace another selected MCP's catalog.

Validation: 67 Node tests, seven native Desktop simulator tests, native loader validation, typechecking and portable distribution checks passed. The new native regression reproduced Claude's exact dropdown rejection before the fix and passes with 130 tools. In the user's actual Claude installation, the real 70-tool catalog stayed visible, paged to entries 64–70, and displayed the final tool's description. Setup streaming, cancellation and remount behavior were verified with native process fixtures; a full live clone is not claimed.
